# KOSPI LAB 24/7 — 주말·야간 실시간 거래소 연동 국내주식 해외 추정가 비교 대시보드

국내주식 정규장(KRX) 휴장 시간(야간·주말·공휴일)에도 **실시간 거래소 WebSocket(Binance Futures & Upbit)** 데이터를 연동하여 국내 7대 주요 종목의 해외 참고가(추정가), 호가창(Orderbook), 글로벌 선행지표, 증권사 컨센서스를 한 화면에서 비교하는 대시보드입니다.

## 주요 기능
- **실시간 거래소 WebSocket 직접 연동**
  - **Upbit WebSocket (`wss://api.upbit.com/websocket/v1`)**: 주말 24시간 실시간 거래되는 원화 테더(`KRW-USDT`) 실세 환율 및 `KRW-BTC` 시세 실시간 수신
  - **Binance Futures WebSocket (`wss://fstream.binance.com/stream`)**: 실시간 선물 체결 틱(`aggTrade`), 5단 호가 깊이(`depth5@500ms`), 실시간 8시간 펀딩비(`markPrice@1s`) 수신
- **7대 주요 종목 KRX 종가 vs 해외 실시간 추정가 비교**
  - 삼성전자(`005930`), SK하이닉스(`000660`), 현대차(`005380`), 한미반도체(`042700`), 삼성전기(`009150`), NAVER(`035420`), LG전자(`066570`)
- **심층 분석 터미널**: 실시간 비교 차트, 원화환산 5단 호가창(롱/숏 잔량비), 증권사 목표주가 컨센서스 및 연도별 영업이익 전망, 내 보유수량 실시간 손익 계산기
